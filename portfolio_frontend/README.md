# Portfolio Frontend

Next.js single-page portfolio (Ocean Professional theme).

## Run

1. Install deps
   npm install

2. Start dev server
   npm run dev

Open http://localhost:3000

## Sections
- Home (Hero)
- Projects
- About
- Skills
- Contact (form posts to /api/contact)

## Notes
- Uses Tailwind CSS with dark high-contrast theme and vibrant accents.
- Images are placeholders in public/images. Replace with real assets for production.
